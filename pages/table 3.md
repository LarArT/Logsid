- La Table 3 de la Classification Décimale de Dewey (CDD) est dédiée aux subdivisions des Littératures, des Formes Littéraires et des Arts. C'est la plus complexe des tables auxiliaires, car elle est divisée en trois parties principales (T3A, T3B, T3C), chacune ayant un rôle spécifique.
  Voici le sommaire exhaustif des trois parties de la Table 3 (T3A, T3B et T3C) :
  Table 3 : Subdivisions pour les Arts, les Littératures, les Genres Littéraires
  La Table 3 est principalement utilisée pour élaborer des indices dans la Classe 800 (Littérature), mais la Table 3C est également utilisée pour affiner certaines classifications dans la Classe 700 (Arts et Loisirs).
  Partie A : T3A - Subdivisions pour les ouvrages par ou sur un seul auteur
  La Table 3A s'applique aux ouvrages traitant d'un seul auteur ou d'une seule œuvre dans une littérature spécifique. Les notations sont ajoutées directement à l'indice de base de la littérature.
  | Subdivision | Description |
  |---|---|
  | \text{-1} | Poésie |
  | \text{-2} | Théâtre (Drame) |
  | \text{-3} | Fiction (Prose narrative) (Roman, nouvelle, conte, etc.) |
  | \text{-4} | Essais et œuvres en prose diverses |
  | \text{-5} | Discours (Allocutions) |
  | \text{-6} | Correspondance (Lettres) |
  | \text{-7} | Humour et Satire |
  | \text{-8} | Œuvres diverses et anthologies (Recueils de formes mélangées) |
  | \text{-9} | Histoire, description, appréciation critique (Ouvrages sur l'œuvre ou la vie de l'auteur) |
  Partie B : T3B - Subdivisions pour les ouvrages par ou sur plusieurs auteurs
  La Table 3B est utilisée pour les ouvrages portant sur les collectifs d'auteurs, l'histoire et la critique d'une littérature par forme et par période, ainsi que pour les recueils (anthologies) d'œuvres de plusieurs auteurs. Les notations sont ajoutées après l'indice de base de la littérature.
  | Subdivision | Description |
  |---|---|
  | \text{-001}–\text{-007} | Subdivisions communes (Similaires à T1, utilisées pour des aspects généraux de la littérature) |
  | \text{-008} | Collections et anthologies d'œuvres littéraires (De plusieurs auteurs) |
  | \text{-009} | Histoire, description, appréciation critique (De la littérature en général, ou d'une forme littéraire) |
  | -1 | Poésie (Histoire, critique, anthologies d'œuvres de plusieurs poètes) |
  | -2 | Théâtre (Drame) (Histoire, critique, anthologies d'œuvres de plusieurs dramaturges) |
  | -3 | Fiction (Prose narrative) (Histoire, critique, anthologies d'œuvres de plusieurs auteurs de fiction) |
  | -4 | Essais et œuvres en prose diverses |
  | -5 | Discours (Allocutions) |
  | -6 | Correspondance (Lettres) |
  | -7 | Humour et Satire |
  | -8 | Œuvres diverses et anthologies (Recueils de formes mélangées) |
  | -9 | Subdivisions pour l'histoire et l'étude (Généralités sur une période, un sujet ou un groupe d'auteurs) |
  La principale différence avec T3A est que T3B comporte des subdivisions pour la période chronologique et le genre littéraire précis (par exemple, T3B-308762 pour la science-fiction en fiction), qui peuvent être ajoutées aux formes ci-dessus.
  Partie C : T3C - Notation supplémentaire pour les arts et la littérature
  La Table 3C est la plus spécifique et est utilisée pour les subdivisions de genres, thèmes et sujets dans les arts et la littérature. Elle est ajoutée là où des instructions spécifiques le demandent.
  | Subdivision | Description |
  |---|---|
  | \text{-1} | Genres des œuvres littéraires et des arts (Ex. : expérimental, parodie, fantasy, science-fiction) |
  | \text{-2} | Thèmes récurrents (Sujets) (Ex. : l'héroïsme, la famille, le crime, le sexe, la mort) |
  | \text{-3} | Caractères et personnages spécifiques (Ex. : personnages historiques, figures mythologiques, personnages féminins) |
  Exemple d'utilisation :
  Pour classer une collection de Science-Fiction (genre) en littérature française (\text{840}), on utiliserait T3B :
   * \text{840} (Littérature française)
   * \text{+} T3B \text{-308762} (Fiction \text{-3}, puis code pour la Science-Fiction)
   * Indice complet : \mathbf{843.08762}
  Pour la critique du thème du voyage dans le temps dans la littérature française, on utiliserait T3C :
   * \text{840} (Littérature française)
   * \text{+} T3B \text{-09} (Critique/Histoire)
   * \text{+} T3C \text{-27} (Thèmes récurrents \text{-2}, puis code pour le voyage dans le temps)
   * Indice complet : \mathbf{840.927}
