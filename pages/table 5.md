  Table 5 : Groupes ethniques et nationaux
  La Table 5 est utilisée pour ajouter une notion de groupe ethnique, national ou linguistique à un sujet. Ces notations, toujours précédées d'un tiret (\text{-}), sont généralement ajoutées aux indices de base seulement lorsque des instructions spécifiques dans les tables générales ou les autres tables auxiliaires le permettent.
  Elle est structurée de manière à refléter la Classification décimale de Dewey de la classe 400 (Langue) et de la classe 900 (Histoire et Géographie), mais elle se concentre sur les populations et non sur les langues ou les lieux.
  | Subdivision | Description |
  |---|---|
  | \mathbf{\text{-01}}–\mathbf{\text{-08}} | Subdivisions communes (Similaires à T1, mais appliquées spécifiquement aux groupes) |
  | \text{-01} | Philosophie et théorie |
  | \text{-02} | Miscellanées |
  | \text{-03} | Dictionnaires, encyclopédies, concordances |
  | \text{-04} | Sujets spéciaux |
  | \text{-05} | Publications en série |
  | \text{-06} | Organisations et gestion |
  | \text{-07} | Éducation, recherche, sujets connexes |
  | \text{-08} | Groupes de personnes |
  | \mathbf{\text{-1}} | Groupes raciaux et ethniques (Peuples selon la race ou l'ethnie) |
  | \text{-11} | Caucasoïdes (Européens) |
  | \text{-12} | Mongoïdes (Asiatiques et Amérindiens) |
  | \text{-13} | Négroïdes (Africains) |
  | \text{-14} | Autres groupes raciaux et ethniques |
  | \mathbf{\text{-2}} | Groupes ethniques selon les sources linguistiques du continent |
  | \text{-21} | Groupes ethniques de l'Afrique du Nord et du Moyen-Orient |
  | \text{-22} | Groupes ethniques d'Asie du Sud |
  | \text{-23} | Groupes ethniques d'Asie de l'Est |

  | \mathbf{\text{-3}}–\mathbf{\text{-9}} | Groupes ethniques et nationaux selon l'indice des langues (Table 6) |
  Application Détaillée (-3 à -9)
  Les subdivisions de \text{-3} à \text{-9} sont de loin la partie la plus détaillée. Elles suivent le schéma de la Table 6 (Langues), ce qui permet d'identifier un groupe national ou ethnique par la langue qu'il parle.
  Pour obtenir la notation détaillée du groupe, il faut utiliser la notation de la Table 6 correspondante, mais en retirant le premier chiffre "4" (puisque la Table 6 commence par 42 pour l'Anglais, 44 pour le Français, etc.).
  | Code (début) | Groupe linguistique principal | Exemple d'utilisation | Indice construit |
  |---|---|---|---|
  | \text{-3} | Langues germaniques | Ouvrages sur les Allemands | \text{-31} |
  | \text{-4} | Langues romanes (italiques) | Ouvrages sur les Français | \text{-41} |
  | \text{-5} | Langues grecques, slaves, indo-iraniennes | Ouvrages sur les Russes | \text{-59} |
  | \text{-6} | Langues afro-asiatiques, nigéro-congolaises | Ouvrages sur les Arabes | \text{-62} |
  | \text{-7} | Langues ouralo-altaïques, dravidiennes | Ouvrages sur les Turcs | \text{-77} |
  | \text{-8} | Langues amérindiennes | Ouvrages sur les Inuits | \text{-85} |
  | \text{-9} | Autres langues | Ouvrages sur les Japonais | \text{-956} |
  Exemple de Construction d'Indice
  Pour classer un document sur la cuisine (641.5) du groupe ethnique français :
   * Indice de base : 641.5 (Cuisine).
   * Code de la langue française (Table 6) : \text{440}.
   * Code du groupe national/ethnique (Table 5) : On retire le "4" du \text{440}, ce qui donne \text{-41}.
   * Application : Le document est classé à \mathbf{641.503941}. (Remarquez l'insertion de \text{-039} (Subdivision commune pour le traitement selon les groupes ethniques et nationaux) pour permettre l'ajout de \text{-41}).
  La Table 5 est cruciale car elle permet de différencier le traitement d'un sujet par un groupe de personnes (Table 5) d'un traitement par lieu géographique (Table 2).
