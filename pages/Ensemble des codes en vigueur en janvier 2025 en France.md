- Le droit français est un système codifié, ce qui signifie qu'il existe un très grand nombre de codes, regroupant les textes législatifs et réglementaires par matière. Il n'est pas possible de dresser une liste exhaustive et stable au jour le jour (en raison des abrogations et des nouvelles codifications), mais voici les principaux codes en vigueur, classés par grands domaines juridiques :
  1. Droit Civil et Judiciaire
  | Code | Domaine |
  |---|---|
  | Code civil | Le fondement du droit privé : personnes, biens, obligations, contrats, responsabilité, famille, successions. |
  | Code de procédure civile | Organisation et déroulement des procès civils. |
  | Code des procédures civiles d'exécution | Réglementation des saisies et autres mesures d'exécution. |
  | Code de l'organisation judiciaire | Organisation des tribunaux judiciaires (tribunaux de commerce, tribunaux judiciaires, etc.). |
  | Code de justice administrative | Organisation des juridictions administratives et déroulement des recours contre les actes de l'administration. |
  2. Droit Pénal
  | Code | Domaine |
  |---|---|
  | Code pénal | Définition des infractions (crimes, délits, contraventions) et des peines applicables. |
  | Code de procédure pénale | Règle les enquêtes, l'instruction et le jugement des infractions pénales. |
  | Code de la justice pénale des mineurs (CJPM) | Règle les procédures spécifiques aux mineurs délinquants. |
  | Code pénitentiaire | Règles relatives à l'exécution des peines et au régime des établissements pénitentiaires. |
  3. Droit Public et Administratif
  | Code | Domaine |
  |---|---|
  | Code des relations entre le public et l'administration (CRPA) | Principes des échanges, des actes unilatéraux, et accès aux documents administratifs (le sujet de votre question précédente). |
  | Code général des collectivités territoriales (CGCT) | Organisation et fonctionnement des communes, départements et régions. |
  | Code de la commande publique | Règles relatives aux marchés publics et aux concessions. |
  | Code de l'expropriation pour cause d'utilité publique | Règles d'acquisition forcée de biens pour l'intérêt général. |
  | Code général de la propriété des personnes publiques (CG3P) | Régime juridique du domaine public et privé des personnes publiques. |
  | Code électoral | Organisation des élections et campagnes électorales. |
  | Code du service national | Obligations militaires des citoyens. |
  4. Droit Économique et Financier
  | Code | Domaine |
  |---|---|
  | Code de commerce | Droit des affaires, sociétés commerciales, fonds de commerce, procédures collectives. |
  | Code de la consommation | Protection et information des consommateurs. |
  | Code de la propriété intellectuelle | Droit d'auteur, brevets, marques et dessins et modèles. |
  | Code monétaire et financier | Institutions et opérations financières et bancaires. |
  | Code général des impôts (CGI) | Règles relatives aux impôts, taxes et droits dus à l'État. |
  | Code des douanes | Réglementation des mouvements de marchandises aux frontières. |
  5. Droit Social et Santé
  | Code | Domaine |
  |---|---|
  | Code du travail | Relations individuelles et collectives de travail (contrat, durée, syndicats). |
  | Code de la sécurité sociale | Organisation et financement de la protection sociale (maladie, retraite, famille). |
  | Code de la santé publique | Organisation du système de santé, professions de santé, produits de santé. |
  | Code de l'action sociale et des familles (CASF) | Dispositions relatives à l'aide et à l'action sociale. |
  | Code de la mutualité | Régime des mutuelles et institutions de prévoyance. |
  6. Droit de l'Environnement et de l'Aménagement
  | Code | Domaine |
  |---|---|
  | Code de l'environnement | Protection de la nature, prévention des risques et des pollutions. |
  | Code de l'urbanisme | Règles d'aménagement du territoire, permis de construire et plans locaux d'urbanisme (PLU). |
  | Code rural et de la pêche maritime | Droit agricole, statut du fermage, pêche maritime. |
  | Code forestier | Réglementation des forêts et bois. |
  | Code de la route | Règles de circulation et sécurité routière. |
  | Code de la construction et de l'habitation (CCH) | Règles de construction des bâtiments et de l'habitat. |
  7. Droit Spécifique
  | Code | Domaine |
  |---|---|
  | Code de l'éducation | Organisation et fonctionnement de l'enseignement. |
  | Code de la défense | Organisation militaire, forces armées et secrets de défense. |
  | Code des assurances | Contrat d'assurance et entreprises d'assurance. |
  | Code de l'entrée et du séjour des étrangers et du droit d'asile (CESEDA) | Règles régissant les étrangers en France. |
  | Code du patrimoine | Protection et conservation du patrimoine (monuments historiques, archives, musées). |
  Cette liste représente les codes les plus couramment cités et utilisés. Le site officiel Légifrance maintient la liste complète et à jour de tous les codes en vigueur.
- Obtenir une liste exhaustive de tous les codes en vigueur en droit français au 1er janvier 2025 relève d'une tâche de maintenance législative qui est du ressort exclusif de l'État. C'est le site officiel Légifrance qui propose cette liste en temps réel.
  En effet, le nombre exact de codes varie en permanence en fonction :
   * Des nouvelles codifications (création de nouveaux codes).
   * Des abrogations (codes qui disparaissent).
   * Des modifications (mises à jour des codes existants).
  Cependant, je peux vous fournir la liste la plus complète possible des codes officiels en vigueur qui existaient autour de cette date (selon les données de Légifrance), classés par domaines pour en faciliter la lecture.
