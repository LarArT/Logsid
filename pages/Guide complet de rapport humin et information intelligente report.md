- ## 1. VUE D'ENSEMBLE HUMINT ET IIR
- ### Définition HUMINT
  Le HUMINT est la collecte d'informations par un collecteur HUMINT entraîné à partir de sources humaines et de documents/médias associés pour identifier :
- Les éléments, intentions, composition
- La force et les dispositions
- Les tactiques, équipements, personnel et capacités
- ### Phases de collecte HUMINT
  Chaque session de questionnement HUMINT comprend 5 phases :
  
  1. **Planification et préparation** : Recherche et planification opérationnelle
  2. **Approche** : Établissement du contrôle et du rapport
  3. **Questionnement** : Utilisation de méthodologies systématiques
  4. **Terminaison** : Finalisation de la session et conditions pour futures collections
  5. **Reporting** : Rédaction, édition et soumission des rapports

- ## 2. TYPES DE RAPPORTS HUMINT
- ### A. SALUTE Report (Immédiat/Tactical)
  
  **Acronyme :** Size, Activity, Location, Unit, Time, Equipment
  
  **Utilisation :**
- Information de valeur tactique immédiate
- Rapportage rapide et concis
- Support des opérations offensives/défensives
  
  **Composants obligatoires :**
  
  | Composant | Description |
  |-----------|-------------|
  | **SIZE** | Nombre de personnel/équipement observé |
  | **ACTIVITY** | Actions observées ou rapportées |
  | **LOCATION** | Lieu spécifique, grille de coordonnées, directions |
  | **UNIT** | Unité d'appartenance ou identification |
  | **TIME** | Date/heure de l'observation ou du rapport |
  | **EQUIPMENT** | Armes, véhicules ou équipement spécifique |
  
  **Exemple Format SALUTE :**
  ```
  SALUTE REPORT
  SIZE: 15-20 military personnel
  ACTIVITY: Movement from northern compound toward main road
  LOCATION: Grid coordinates: 42SXD 23456 78901 (or 2 km north of Al-Qasim)
  UNIT: Unknown, believed to be Anti-Coalition Militia
  TIME: 28 MAR 2006, 1430 hours local
  EQUIPMENT: Estimated 4-6 PKM machine guns, AK-47 rifles, 2 technical vehicles
  REPORTING SOURCE: Local informant (Reliability: B / Credibility: 2)
  ```

  ### B. Intelligence Information Report (IIR)
  
  **Définition :** Rapport systématique contenant des informations recueillies auprès de sources HUMINT analysées et organisées selon les exigences de collecte.
  
  **Utilisation :**
  - Rapportage detaillé et structuré
  - Évaluation source et fiabilité information
  - Support pour all-source analysis
  - Évaluations stratégiques et opérationnelles
  
  **Avantages de l'IIR :**
  - Fournit contexte complet de l'information
  - Permet traçabilité source
  - Facilite intégration dans all-source system
  - Supporte analyse d'ordre de bataille
  - Cross-cueing vers autres disciplines intelligence
  
  ### C. Rapport narratif long terme
  
  **Utilisation :**
  - Debriefings étendus
  - Briefings stratégiques
  - Documents de source associés (DOCEX)
  - Analyse détaillée de réseaux
  
  **Caractéristiques :**
  - Format de rapport continu
  - Sections thématiques organisées
  - Résumé exécutif quand approprié
  - Citations directes/indirectes mentionnées

  ## 3. PRINCIPES DE REPORTING
  
  ### Principes Fondamentaux
  
  #### 1. **Précision et Honnêteté**
  - Tous les faits rapportés doivent être vérifiés autant que possible
  - Distinguer entre information confirmée et supposition
  - Rapporter les limitations de la source
  
  #### 2. **Clarté et Concision**
  - Langage direct et compréhensible
  - Éviter jargon excessif non défini
  - Structurer l'information logiquement
  
  #### 3. **Opportunité (Timeliness)**
  - Rapports SALUTE : transmission immédiate (heures)
  - Rapports IIR : dans les 24-48 heures
  - Information critique : temps réel si possible
  
  #### 4. **Pertinence aux Exigences**
  - Répondre directement aux Specific Information Requirements (SIR)
  - Cross-referencer les PIR (Priority Information Requirements)
  - Identifier gaps non comblés
  
  #### 5. **Attribution Source**
  - Identifier type de source (humain, document, liaison)
  - Évaluation fiabilité source
  - Évaluation crédibilité information
  - Métadonnées source (date, lieu, circonstances)
  
  #### 6. **Chaîne de Commandement**
  - Suivre protocol de distribution établi
  - Validation par superviseur avant transmission
  - Respect des niveaux classification
  
  ### Cycle de Reporting HUMINT
  
  ```
  Collection → Évaluation → Analyse → Édition → Validation → Distribution
       ↑                                                              ↓
       └─────────────────── Feedback & Refinement ─────────────────┘
  ```

  ## 4. ARCHITECTURE DE REPORTING
  
  ### Flux de Rapport Type
  
  **Au niveau collecteur :**
  1. Interrogateur/collecteur complète rapport brut
  2. Superviseur immédiat revue et édition
  3. Transmission au HOC (HUMINT Operations Cell)
  4. Validation technique
  
  **Au niveau HOC :**
  1. Revue conformité format/classification
  2. Vérification couverture exigences
  3. Comparaison données existantes
  4. Identification cross-cue possibles
  5. Release authority approval
  6. Distribution
  
  **Au niveau analyse :**
  1. Réception dans all-source system
  2. Intégration source database
  3. Croisement avec autres disciplines
  4. Production intelligence products
  
  ### Niveaux de Validation
  
  | Niveau | Responsabilité |
  |--------|-----------------|
  | **HCT Leader** | Validation rapport initial |
  | **OMT** | Revue technique et opérationnelle |
  | **HOC** | Validation conformité et pertinence |
  | **C/J/G/S2X** | Release authority final |
  | **ACE/HAC** | Intégration analyse |

  ## 5. STRUCTURE DES RAPPORTS TYPE
  
  ### Structure Standard IIR
  
  #### En-tête (HEADER)
  ```
  CLASSIFICATION: //NOFORN
  SOURCE DOCUMENT NUMBER: [CODE]-[NUMBER]-[DATE]
  ORIGINATOR: [Unit/Organization]
  DATE REPORTED: [Date Time Group]
  REPORTED BY: [Collector Name/Designation]
  SUBJECT: [Concise subject line, typically 3-4 words]
  AREA OF INTEREST: [Geographic area]
  ```
  
  #### SUMMARY/RÉSUMÉ EXÉCUTIF
  ```
  3-5 phrases couvrant :
  - Main point/conclusion
  - Time-sensitive information
  - Critical intelligence value
  ```
  
  #### BODY (CORPS PRINCIPAL)
  ```
  Structured by topic or following PIR order:
  
  1. SOURCE IDENTIFICATION
     - Type de source (détenu, civil, document, etc.)
     - Accès/placement de la source
     - Fiabilité historique
     - Limitations de la source
  
  2. DETAILED INFORMATION
     - Information par domaine (ordre de bataille, intentions, capacités)
     - Contexte fourni par la source
     - Détails spécifiques
     - Clarifications techniques
  
  3. ASSESSMENT
     - Évaluation crédibilité information
     - Cross-check avec données existantes
     - Inconsistances identifiées
     - Requêtes information supplémentaires
  
  4. INTELLIGENCE GAPS
     - Informations demandées mais non obtenues
     - Limitations source
     - Besoins de follow-up
  ```
  
  #### Source and Information Credibility Matrix
  ```
  SOURCE RELIABILITY:        INFORMATION CREDIBILITY:
  A - Completely reliable    1 - Confirmed by other sources
  B - Usually reliable       2 - Probably true
  C - Fair reliability       3 - Possibly true
  D - Low reliability        4 - Doubtful
  E - Unreliable            5 - Improbable
  F - Cannot be judged      6 - Cannot be judged
  ```
  
  #### CLASSIFICATION ET DISTRIBUTION
  ```
  CLASSIFICATION: [SECRET//NOFORN] ou [UNCLASSIFIED//FOUO]
  DISTRIBUTION: [PIR Owner], [G2/S2], [ACE], [JIDC], etc.
  ORIGINATED BY: [Collector Unit]
  CLEARED BY: [OMT Leader/HOC Chief]
  ```

- ## 9. CONTRÔLE DE QUALITÉ ET VALIDATION
- ### Checklist de Validation des Rapports
- #### Avant Transmission (Collecteur/OMT)
- [ ] **Exactitude des faits**
	- Aucune embellissement des informations
	- Distinction claire entre observation directe et interprétation
	- Citation directe mises entre guillemets
- [ ] **Pertinence aux exigences**
	- Adresse au moins un SIR/PIR identifié
	- Cross-référence aux exigences de collecte
	- Identification des gaps d'information
- [ ] **Fiabilité source documentée**
	- Évaluation fiabilité source présente
	- Évaluation crédibilité information présente
	- Justification des évaluations fournie
- [ ] **Métadonnées complètes**
	- Date/heure de collecte
	- Méthode d'acquisition (interrogatoire, documents, liaison)
	- Numéro de source ou code de source
	- Collecteur identifié
	- Superviseur validation
- [ ] **Structure et format**
	- Format approprié (SALUTE/IIR/Narratif)
	- Classification correcte
	- Distribution list complète
- #### Au niveau HOC/Release Authority
- [ ] **Conformité classification**
	- Marquage correct
	- Informations sensibles protégées
	- Déclassification dates appropriées
- [ ] **Pertinence opérationnelle**
	- Information fournit support à opérations actuelles
	- Pas de dupliquata du reporting antérieur
	- Identification si information confirme/contredit rapports antérieurs
- [ ] **Intégrité source**
	- Protection de l'identité source appropriée
	- Évaluation des risques pour source
	- Mesures contre-CI si appropriées
- [ ] **Faisabilité distribution**
	- Système de distribution fonctionne
	- Destinataires appropriés identifiés
	- Protection communications établie
- ### Indicateurs de Qualité Rapport
  
  | Qualité | Indicateurs |
  |---------|------------|
  | **Excellent** | Spécifique, détaillé, cross-référencé, source fiable, pertinent PIR |
  | **Bon** | Factuel, source crédible, pertinent exigences, informations complètes |
  | **Acceptable** | Informations valides, pertinence établie, source raisonnablement fiable |
  | **Faible** | Vague, généralités, source fiabilité questionnable, pertinence limitée |
  | **Inutilisable** | Spéculation, source non fiable, non pertinent, informations incorrectes |

- ## CONCLUSION
  
  Les rapports HUMINT, qu'ils soient au format SALUTE immédiat, IIR détaillé, ou narratif stratégique, constituent la base du soutien du renseignement humain aux opérations militaires. Le respect rigoureux des principes de reporting—précision, clarté, opportunité, pertinence et évaluation source adéquate—assure que les décideurs reçoivent des informations exploitables et fiables.
- ### Points Clés à Retenir
  
  1. **Format approprié au besoin** : SALUTE pour immédiat tactique, IIR pour détaillé, narratif pour stratégique
  2. **Évaluation source systématique** : Fiabilité et crédibilité toujours documentées
  3. **Validation de chaîne de commandement** : Chaque rapport suit processus d'approbation établi
  4. **Cross-référence aux exigences** : Chaque rapport adresse PIR/SIR identifié
  5. **Feedback et refinement** : Processus continu d'amélioration basé sur utilisation requête
